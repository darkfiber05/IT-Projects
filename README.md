# IT Projects — Aidan Boynton

A collection of full-stack web projects I've designed, built, and deployed — covering frontend design, backend/database integration, automation, and client-facing SaaS-style products.

## Projects

### 🌿 [College Bound Landscaping — Business Website](./landscaping-website)
A full digital storefront for a landscaping business: booking/quote form, live database, automated email notifications, and an internal AI-assisted email response dashboard.
- **Stack:** HTML/CSS/JS, Supabase (Postgres + Edge Functions), Resend (transactional email), Netlify (hosting)
- **Live:** https://bucolic-madeleine-420f7f.netlify.app

### 💼 [College Bound Web Services (CBWS) — Agency Website](./cbws-agency-site)
A premium agency-style marketing site for a web development service business, offering website builds to local small businesses. Includes lead capture, pricing/comparison tables, portfolio, and FAQ.
- **Stack:** HTML/CSS/JS, Supabase (lead database), Resend (lead notifications), GoDaddy (subdomain hosting)
- **Live:** https://cbwebservices.intellivn.com

### 🏥 [HMI Hackathon — Asynchronous Telehealth Platform](./hmi-hackathon-telehealth)
An asynchronous telehealth platform prototype built for a hackathon, tackling the problem of limited patient access when telehealth relies solely on scheduled video calls. Features patient/doctor dashboards, drone delivery tracking with live GPS, an interactive body-pain-map SVG selector for symptom reporting, and a 3D D3.js globe for provider region selection.
- **Stack:** Google AI Studio app (React/TypeScript, D3.js + TopoJSON, custom SVG)
- **Live:** https://ai.studio/apps/6921a4a0-b430-4eb8-ab46-018c9ffa95cd
