# College Bound Web Services (CBWS) — Agency Website

**Live site:** https://cbwebservices.intellivn.com

## Overview
A premium, agency-style marketing website for a web development service business (College Bound Web Services) that builds and hosts websites for local small businesses that lack an online presence.

## Features
- Modern responsive design (navy/gold branding, animated hero, scroll-reveal sections)
- Comparison table (CBWS vs. other agencies), portfolio section, pricing tiers, FAQ accordion
- Lead capture form for prospective business clients, writing to a dedicated Supabase table
- Supabase Edge Function + Resend integration for instant lead notification emails
- Deployed on a custom subdomain via GoDaddy/cPanel hosting

## Stack
- **Frontend:** HTML, CSS, JavaScript
- **Database/Backend:** Supabase (Postgres, Edge Functions, Row Level Security)
- **Email:** Resend
- **Hosting/DNS:** GoDaddy (cPanel, subdomain configuration)

## My Role
Designed and built the full site, set up the lead-capture database and automated notification pipeline, and produced accompanying sales/marketing collateral (print flyer, sales scripts) used to pitch the service to local businesses.
