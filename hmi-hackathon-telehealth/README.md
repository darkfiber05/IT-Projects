# HMI Hackathon — Asynchronous Telehealth Platform

## Overview
A telehealth platform prototype built during a hackathon, designed to support asynchronous patient-doctor interactions.

## Features
- Patient and doctor dashboards
- Drone delivery tracking for prescriptions/supplies
- Interactive body-pain-map SVG selector for symptom reporting

- Google AI Studio app
