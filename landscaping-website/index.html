⚙️ Setup Guide

1️⃣ ImgBB (Free Image Host — 5 min)

Twilio MMS needs a public URL for photos. ImgBB hosts them free.

  1. Go to https://api.imgbb.com → click "Get API key" → sign up free
  2. Copy your API key and paste it as IMGBB_API_KEY in the CONFIG block

2️⃣ Twilio (Free Trial — 10 min)

  1. Go to https://www.twilio.com → sign up for a free trial
  2. Verify your real phone number (678-997-7134) during sign-up
  3. Get a free Twilio phone number (this is what sends the texts)
  4. From your Twilio Console dashboard, copy:
    • Account SID → paste as TWILIO_ACCOUNT_SID
    • Auth Token → paste as TWILIO_AUTH_TOKEN
    • Your Twilio number → paste as TWILIO_FROM_NUMBER (format: +1xxxxxxxxxx)
  5. ⚠️ Free trial only sends to verified numbers. Upgrade ($15/mo) to receive from anyone.

3️⃣ Google Sheets (Free — 15 min)

  1. Go to https://sheets.google.com → create a new sheet named "Landscaping Leads"
  2. Add these headers in Row 1 (copy exactly):
    Timestamp | First Name | Last Name | Phone | Email | Address | Service | Preferred Date | Best Time | Notes
  3. Go to Extensions → Apps Script
  4. Delete the default code and paste this:
    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.timestamp, data.firstName, data.lastName,
    data.phone, data.email, data.address,
    data.service, data.date, data.time, data.notes
  ]);
  return ContentService
    .createTextOutput(JSON.stringify({result:'success'}))
    .setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  return ContentService
    .createTextOutput(JSON.stringify({result:'ok'}))
    .setMimeType(ContentService.MimeType.JSON);
}
  5. Click Deploy → New deployment → Web app
  6. Set "Execute as" = Me, "Who has access" = Anyone

4️⃣ Hosting (Free — 5 min)

Upload this single HTML file to Netlify Drop (drag & drop at netlify.com/drop) or GitHub Pages. You'll get a free public URL instantly.
